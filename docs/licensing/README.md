# Politique de licence et redistribution

Ce dossier matérialise la décision de licence globale de **Guide IA GameDev**.

## Décision

- documentation, chapitres, contenus narratifs et exports éditoriaux : `CC-BY-SA-4.0` ;
- code, scripts, workflows, schémas techniques et fixtures de test : `MIT` ;
- métadonnées factuelles explicitement classées : `CC0-1.0` ;
- composants tiers : licence d'origine, jamais remplacée par la politique globale.

La licence exacte d'un fichier est résolue selon l'ordre défini dans `../../LICENSE.md`. La matrice YAML est la source machine-readable utilisée par la CI.

## Pourquoi plusieurs licences ?

Creative Commons recommande ses licences pour les contenus créatifs et la documentation, mais pas pour le logiciel. La licence MIT est donc utilisée pour les ressources exécutables et techniques. CC BY-SA protège l'attribution et impose le partage à l'identique des adaptations éditoriales. CC0 facilite la réutilisation de données purement factuelles explicitement identifiées.

## Publication

Une publication doit :

1. embarquer la notice d'attribution dans le PDF, HTML ou EPUB ;
2. inclure les textes et notices de licence dans les archives ;
3. produire un inventaire des composants tiers réellement redistribués ;
4. exclure tout élément dont la licence ou la provenance ne sont pas établies ;
5. indiquer les modifications apportées aux contenus CC BY-SA.
