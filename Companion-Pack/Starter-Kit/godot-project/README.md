# Projet Godot — Project Asteria Starter Kit

Ouvrir `project.godot` avec Godot Standard `4.7.1-stable`.

Entrées :

- scène principale : `res://src/features/bootstrap/main.tscn` ;
- rapport : `res://src/core/bootstrap_report.gd` ;
- tests : `res://tests/run_tests.gd` ;
- validation statique : `tools/validate_project.py`.

Le projet ne requiert aucun addon et ne contacte aucun service réseau.
