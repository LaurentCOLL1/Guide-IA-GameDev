# Profils d’environnement

Les profils décrivent l’enveloppe de gouvernance et les plateformes exigées. Ils ne contiennent ni secret, ni chemin local absolu, ni paramètre d’autorité gameplay.

- `solo/profile.json` : une personne, Windows obligatoire, auto-revue différée ;
- `studio/profile.json` : revue indépendante, Windows et Linux exigés.

Le profil actif du bootstrap reste `solo` tant qu’aucune composition explicite ne le remplace.
