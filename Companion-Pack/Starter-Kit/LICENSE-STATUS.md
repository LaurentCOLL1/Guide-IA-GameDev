# Statut de licence et de redistribution

## État

`pending-global-license`

La licence globale du projet `Guide-IA-GameDev` n’est pas encore décidée. En conséquence, ce Starter Kit ne doit pas être redistribué comme paquet autonome, intégré à un produit tiers ou republié sous une licence supposée.

## Portée

- les fichiers du Starter Kit sont originaux et textuels ;
- aucun binaire Godot n’est inclus ;
- aucun asset, modèle, voix, donnée personnelle ou secret tiers n’est inclus ;
- les liens vers Godot n’emportent aucune redistribution du moteur ;
- la licence MIT de Godot ne s’étend pas automatiquement aux fichiers de ce dépôt.

## Action requise avant publication

La décision de licence globale doit préciser séparément le texte documentaire, le code, les données synthétiques, les médias éventuels et les archives du Companion Pack. Une notice finale remplacera ce statut avant toute release publique.
