# Compatibilité

- Python : 3.10 ou plus récent ;
- Godot : 4.7.1-stable qualifié sur Linux x86_64 ;
- GDScript : typage volontairement modéré pour rester copiable ;
- aucune dépendance réseau, base de données ou addon.

Windows graphique, Forward+ sur GPU réel, export et performance ne sont pas qualifiés par ce pack.
