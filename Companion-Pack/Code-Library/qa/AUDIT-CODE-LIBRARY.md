# Audit candidat

Le lot couvre les neuf familles prévues avec des ports Python et GDScript déclarés. Le registre d’API interdit les doublons intra-langage et protège les concepts déjà propriétaires des autres packs.

La décision finale dépend des tests Python, de l’import et des tests Godot, des démarrages bornés et du contrôle d’arbre propre.
