# Sécurité

- Ne jamais écouter sur toutes les interfaces pendant la qualification.
- Ne jamais installer automatiquement les custom nodes suggérés par un workflow reçu.
- Traiter tout custom node comme du code Python avec les droits du compte.
- Refuser les chemins sortant du Pack dans les validateurs.
- Exclure secrets, cookies, jetons, références personnelles et images d’entrée non autorisées.
- Conserver les sorties nouvelles en quarantaine jusqu’à la revue humaine.
