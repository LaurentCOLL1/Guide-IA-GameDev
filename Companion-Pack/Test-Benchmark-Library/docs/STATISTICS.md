# Statistiques

Le Pack utilise les observations après warm-up. La variance et l’écart-type sont ceux de l’échantillon lorsque deux observations ou plus existent. Les percentiles utilisent une interpolation linéaire sur la série triée. Le coefficient de variation est `écart-type / moyenne` lorsque la moyenne est non nulle.

Aucune valeur aberrante n’est supprimée automatiquement. Une exclusion future doit être enregistrée avec sa règle, sa justification et les données originales.
