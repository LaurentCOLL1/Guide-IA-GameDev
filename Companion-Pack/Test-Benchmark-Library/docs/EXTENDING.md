# Étendre la bibliothèque

1. créer un contrat stable ;
2. fournir une fixture redistribuable et une seed ;
3. définir un oracle fonctionnel indépendant du chronométrage ;
4. exposer une exécution séparée ;
5. conserver les échantillons bruts ;
6. ajouter des tests du format et des erreurs ;
7. documenter les limites matérielles et logicielles.
