# Données redistribuables

Les fixtures et le corpus fournis sont synthétiques. Aucun texte utilisateur, secret, dépôt privé, asset tiers, modèle ou sortie propriétaire ne doit être ajouté aux campagnes versionnées.

Les résultats locaux peuvent révéler des informations matérielles. Avant partage public, vérifier qu’ils ne contiennent ni hostname, ni nom d’utilisateur, ni chemin personnel.
