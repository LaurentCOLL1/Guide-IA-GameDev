# Interprétation bornée

- `functional-pass` : l’oracle et le format sont valides ;
- `local-measurement` : une durée ou mémoire a été observée dans l’environnement enregistré ;
- `same-environment-comparison` : deux campagnes compatibles peuvent être rapprochées ;
- `not-comparable` : une porte d’identité ou d’environnement diffère ;
- `illustrative-only` : exemple de format, jamais preuve runtime.

Un delta numérique ne devient pas automatiquement une amélioration pratique.
