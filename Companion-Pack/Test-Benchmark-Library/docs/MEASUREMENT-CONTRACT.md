# Contrat de mesure

Chaque benchmark déclare avant exécution : identifiant, version, question, métrique primaire, unité, direction, warm-up, répétitions, seed, charge, oracle fonctionnel et limites.

Les observations brutes sont conservées. Les agrégats ne remplacent jamais les échantillons. Une erreur fonctionnelle invalide la mesure correspondante.
