# Statut de redistribution

Le Pack 5 est créé pour ce dépôt. La licence globale de la collection reste indécise.

- code tiers copié : aucun ;
- paquet Python runtime tiers : aucun ;
- SQL tiers copié : aucun ;
- addon ou binaire SQLite/Godot : non versionné ;
- données personnelles et secrets : absents ;
- fixtures : synthétiques et fictives ;
- qualification runtime : ne constitue pas une autorisation de redistribution ;
- redistribution autonome : bloquée jusqu’à la décision de licence globale.
