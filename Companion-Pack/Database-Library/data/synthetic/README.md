# Données synthétiques

`asteria-fixture.json` contient uniquement des identifiants et textes fictifs déterministes. Il ne contient aucune donnée personnelle, sauvegarde joueur, secret, contenu tiers ou donnée collectée.

Le seeder Python charge ce fichier, valide sa version de schéma, puis utilise exclusivement les repositories publics du Pack 5. Les données peuvent être supprimées et recréées.
