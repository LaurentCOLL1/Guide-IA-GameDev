# Politique CODEOWNERS

Le fichier `.github/CODEOWNERS` est fourni avec `__OWNER_HANDLE__` comme valeur initiale.

Avant utilisation réelle :

1. remplacer les propriétaires génériques par des comptes ou équipes existants ;
2. vérifier les permissions d’écriture ;
3. activer la revue CODEOWNERS dans la protection de branche ;
4. tester une pull request sur chaque chemin sensible ;
5. documenter les chemins sans propriétaire.

La présence du fichier seule ne prouve pas son application.
