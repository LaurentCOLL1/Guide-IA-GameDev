# ADR-0001 — Profil de projet __PROFILE_ID__

- statut : accepté comme valeur initiale du modèle
- profil : `__PROFILE_ID__`
- propriétaire déclaré : `__OWNER_HANDLE__`
- mode de revue : `__REVIEW_MODE__`
- réviseurs requis dans la politique : `__REQUIRED_REVIEWERS__`
- approbation de release : `__RELEASE_APPROVAL__`

## Décision

Le projet adopte le profil `__PROFILE_ID__` comme enveloppe opérationnelle initiale.

## Limite

Cette ADR matérialise une politique de départ. Elle ne prouve pas que les protections de branche, permissions ou approbations sont configurées sur un hébergement Git réel.
