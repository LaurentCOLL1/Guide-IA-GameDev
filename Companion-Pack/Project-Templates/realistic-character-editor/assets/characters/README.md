# Emplacement des personnages réalistes

Placez ici le corps principal exporté depuis Blender :

```text
human_base.glb
```

Le GLB doit contenir au moins un `MeshInstance3D` avec les blend shapes définies dans :

```text
../../scripts/blend_shape_driver.gd
```

Aucun asset humain, scan corporel, texture de peau ou module anatomique explicite n’est distribué avec ce prototype. Tout contenu ajouté dans ce dossier doit posséder une provenance, une licence et un droit d’utilisation documentés.

Pour les personnages de moins de 18 ans, le corps importé doit rester non explicite et compatible avec le vêtement de confidentialité obligatoire.
