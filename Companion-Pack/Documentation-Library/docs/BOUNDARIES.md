# Frontières de la Documentation Library

Le Volume 0 reste la source normative des règles documentaires. Les Livres restent les contenus pédagogiques et encyclopédiques propriétaires. Le Pack 7 fournit seulement des patrons, profils fictifs, schémas et outils de génération.

Le Pack ne doit pas :

- copier un chapitre complet ;
- introduire une seconde convention d’identifiants ;
- décider à la place du glossaire officiel ;
- publier un résultat de QA sans exécution ;
- générer automatiquement une entrée dans `contents.txt` ;
- produire un PDF ou déclarer une qualité visuelle non inspectée.
