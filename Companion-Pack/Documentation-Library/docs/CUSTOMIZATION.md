# Personnaliser un patron

1. Dupliquer le profil JSON correspondant, jamais le patron pour une seule occurrence.
2. Attribuer un identifiant conforme et non réutilisé.
3. Remplacer toutes les valeurs factuelles, versions, chemins et réserves.
4. Conserver le front matter, le titre de niveau 1 et les repères d’utilisation.
5. Générer dans un dossier de travail.
6. Exécuter le validateur et compiler vers HTML avec Pandoc.
7. Faire relire le document avant de l’ajouter à un Livre, au Volume 0 ou au Companion Pack.

Un champ absent du besoin doit être retiré avec une décision explicite ; il ne doit pas être rempli par une valeur inventée.
