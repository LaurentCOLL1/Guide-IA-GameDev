# Textes et notices de licence

Ce dossier contient les textes ou notices nécessaires à la politique de licences multiples du dépôt :

- `MIT.txt` — texte intégral de la licence MIT ;
- `CC-BY-SA-4.0.txt` — identifiant SPDX et liens vers le code juridique canonique ;
- `CC0-1.0.txt` — identifiant SPDX et liens vers le code juridique canonique.

La portée de chaque licence est définie dans `../LICENSE.md` et `../docs/licensing/LICENSE-MATRIX.yaml`.
